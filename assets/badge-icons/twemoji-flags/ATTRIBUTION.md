# Twemoji flags artwork

Artwork by b3yc0d3 and contributors from [twemoji-flags](https://github.com/b3yc0d3/twemoji-flags), pinned to commit `1eee036f2567edc1f56f7dcb4105eae5a347cc7b`. The 39 flag SVGs used here are copied without modifications and licensed under [CC BY 4.0](LICENSE-GRAPHICS). The upstream software license is preserved in [LICENSE](LICENSE); no upstream build code is used.

The manifest records every source SVG, local badge mapping, and SHA-256 checksum. `TEMPLATE_FLAG.svg` is an empty authoring template and is excluded, as in the upstream build. The upstream heterosexual flag is left out on purpose. 46 additional locally drawn flags take their silhouette from the pinned upstream template and add locally drawn stripes and symbols. These adapted graphics keep the CC BY 4.0 attribution, and the manifest lists them separately from the 39 unchanged upstream flag images.
